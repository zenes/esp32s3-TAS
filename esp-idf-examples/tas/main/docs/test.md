# WiFi iPerf 속도 측정 가이드

본 문서는 ESP-IDF의 `wifi/iperf` 예제를 활용하여 ESP32를 무선 공유기(SoftAP) 모드로 켜고, Mac(또는 PC)과 연결하여 대역폭(속도)을 측정하는 절차를 안내합니다.

## 1. ESP32를 AP(핫스팟) 모드로 구동
터미널의 `iperf>` 프롬프트에서 접속할 설정값을 입력하여 AP 모드를 구동합니다.

```bash
# 1. 원하는 와이파이 이름(esp_ap)과 비밀번호(12345678)로 AP 구동
iperf> ap esp_ap 12345678

# 2. ESP32의 AP IP 주소 확인 (보통 192.168.4.1 로 할당됨)
iperf> query
```

## 2. PC(Mac)에서 연결
1. PC의 WiFi 설정에서 `esp_ap` 네트워크를 선택합니다.
2. 비밀번호 `12345678`을 입력하여 기기 간 내부망 연동을 완료합니다.

---

## 3. 대역폭 성능 측정 시나리오

최고 성능(가장 부하가 적은 통신)을 계측하기 위해 UDP(`-u`) 프로토콜을 사용합니다. 측정 전 PC에 `iperf` 가 설치되어 있어야 합니다.

### 시나리오 A: PC -> ESP32 전송 속도 측정
가장 일반적인 테스트로, ESP32가 데이터를 얼마나 빠르게 수신할 수 있는지 확인합니다.

1. **ESP32 (수신 서버 오픈)**
   ```bash
   # UDP 모드(-u)로 서버 대기(-s), 3초마다(-i 3) 리포트 출력
   iperf> iperf -u -s -i 3
   ```
2. **PC (새 터미널 열고 송신)**
   ```bash
   # ESP32(192.168.4.1)로 50M 대역폭(-b 50M)을 30초간(-t 30) 쏘기
   iperf -u -c 192.168.4.1 -b 50M -t 30 -i 3
   ```

### 시나리오 B: ESP32 -> PC 전송 속도 측정
ESP32가 데이터를 가공한 뒤 얼마나 빠르게 외부로 송신할 수 있는지 확인합니다.

1. **PC (수신 서버 오픈)**
   ```bash
   iperf -u -s -i 3
   ```
2. **ESP32 (송신)**
   ```bash
   # PC가 할당받은 IP를 적어줍니다 (예: 192.168.4.2)
   iperf> iperf -u -c 192.168.4.2 -t 30 -i 3
   ```

## 4. 테스트 종료 및 유의사항
* 진행 중인 iperf 세션을 도중에 강제 중단하려면 ESP 터미널에 아래 명령어를 입력합니다.
  ```bash
  iperf> iperf -a
  ```
* ESP-IDF 기본 예제는 W5500(하드웨어 이더넷)과 연동되지 않고 기본 무선(WiFi)과 소프트웨어적인 lwIP 환경 기반에서만 동작합니다.
